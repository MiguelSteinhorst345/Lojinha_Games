# Lojinha Games

Sistema desktop para gerenciamento de uma **Lojinha de games** desenvolvida em **Java Swing** com persistência em **MySQL via JDBC**, seguindo o padrão **MVC + DAO**.

O sistema permite cadastro, edição, exclusão e listagem de jogos **upload e preview de imagens** dos produtos 

---
# Funcionalidades do projeto:
- Cadastro de jogos
- Edição de jogos
- Exclusão de jogos
- Listagem em JTable
- Upload de imagem do produto
- Preview de imagem
- Armazenamento local de imagem
- Integração com MySQL
- ---
# Tecnologias Utilizadas
- Java
## Interface Gráfica
- Java Swing
- JForm (GUI Builder do Netbeans)
- ## Banco de dados
- MySQL
- JDBC (Java Database Connectivity
